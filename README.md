# Auto Resume Generator 🚀

> 一个基于人工智能的自动简历生成器（Web App），超越传统 LaTeX 简历的现代渲染体验。

## 🌟 项目简介

这是一个完全基于现代 Web 分离架构打造的“傻瓜式”智能简历生成器。相比于重度依赖 LaTeX 编译链、环境配置复杂的同类竞品（如 RenderCV），本项目具有以下核心特色：

1. **防 AI 幻觉的中间态交互**：拒绝盲盒式的“一键出 PDF”。所有的结构化解析均有中间态展现（左侧编辑，右侧预览），你可以直观拦截并修改 AI 瞎编的内容，安全可控。
2. **零成本极速渲染 (`@media print`)**：完全无需在后端挂载笨重、易崩溃的 Playwright / Puppeteer 无头浏览器。本应用直接利用现代浏览器自带的高级分页排版能力，利用前端 Tailwind CSS 打印指令直接导出极高清的跨平台 PDF。
3. **免封禁 API 架构 (Single-Prompt)**：不再为简历上的每一份单独经历发散调用 AI。后端采用一次性的结构转换指令，配合并发锁（Semaphore），不仅最大化节约了免费 Token，更能在白嫖额度下绝对防止账号被封禁。

## 🏗️ 架构说明

本项目基于 **前后端分离但单体部署** 设计：

- **前端层 (UI & 渲染)**：
  - 基于 `Vue 3` 与 `Tailwind CSS v4`。
  - 左侧为交互式 AI 生成/草稿修改界面，右侧为一个永远保持 A4 长宽比的完美排版组件。
  - 通过 CSS `print:xxxx` 后缀控制导出状态下隐藏工具栏并重置背景，实现丝滑体验。
- **后端层 (AI & 控制)**：
  - 基于 `FastAPI` (Python)。
  - `ai_service.py` 负责驱动 Google Gemini 获取结构化的 `Pydantic` JSON 数据。
  - 静态挂载了由 Vite 编译出来的打包资产，实现 **“只要一行 Python 代码即可一并启动前后端”** 的极其方便的开源部署体验。

## 🛠️ 快速启动 (Local Setup)

为了方便开源用户和小白快速把玩，项目将前后端运行合并在了一起。

### 环境要求
- Node.js >= 18 (用于编译前端现代组件)
- Python >= 3.10 (用于运行大模型后端接口)

### 第一步：克隆与依赖配置

克隆此仓库后，进入根目录，安装后端依赖即可：

```bash
pip install -r requirements.txt
```

### 第二步：配置免费 API Token

将根目录下的 `.env.example` 复制一份并改名为 `.env`，填入你的免费 API 密钥（目前默认支持 Gemini 2.0 Flash，额度极大）：

```env
GEMINI_API_KEY=your_google_gemini_key_here
```

### 第三步：一键运行

在项目根目录下直接执行专属引导脚本：

```bash
python run.py
```
> **自动构建机制：**
> 如果 `run.py` 发现前端 `frontend/dist` 文件夹不存在，它会自动帮你执行 `npm install` 与 `npm run build`，全程零心智负担。

当终端提示 `Uvicorn running on http://127.0.0.1:8000` 时，打开浏览器即可开始使用！
